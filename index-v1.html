📖 Guide d'utilisation

① Convertir une sourate (Coran)

  1. Choisir sourate + langue + récitateur.
  2. Cliquer sur ⚡ Convertir. L'API fusionne arabe + traduction + audio.

② Ajouter une ressource académique

  1. Glisser-déposer un fichier (PDF, DOCX, EPUB, MP3, MP4…).
  2. Le titre est pré-rempli (modifiable).
  3. Cliquer sur 🔍 Tester pour prévisualiser / pré-écouter.
  4. Choisir « chemin » ou « base64 » (case en haut).
  5. Cliquer sur ➕ Ajouter tous à la biblio.

③ Stockage

La biblio est automatiquement sauvegardée dans le localStorage. Le panneau ③ affiche la taille utilisée et permet de forcer une sauvegarde ou de recharger depuis le navigateur.

④ Export vers le Mini-agent

  1. Cliquer sur 📤 Exporter data.json.
  2. Copier le fichier dans /biblio/data.json à côté du Mini-agent.
  3. Si mode « chemin » : copier aussi les MP3/MP4/PDF dans /biblio/.
  4. Le Mini-agent doit faire fetch('biblio/data.json') au démarrage.

⑥ Classification automatique

  • document : PDF, DOC, DOCX, TXT, MD
  • book : EPUB
  • audio : MP3, WAV, M4A, OGG
  • video : MP4, WEBM, MOV
