📖 Guide d'utilisation

① Convertir une sourate

  1. Choisir sourate, langue et récitateur.
  2. Cliquer ⚡ Convertir. L'API alquran.cloud est appelée.
  3. La sourate est stockée (métadonnées en localStorage, blobs en IndexedDB).
  4. Cliquer sur la sourate dans la biblio pour la lire verset par verset.

② Ressources académiques

  1. Glisser-déposer PDF, audio ou vidéo dans la zone.
  2. Modifier le titre si besoin, tester avec 🔍.
  3. Cliquer ➕ Tout ajouter.

③ Synchronisation avec l'agent principal

  • BroadcastChannel : synchronisation automatique dans le même navigateur.
  • postMessage : si l'agent est dans un iframe ou fenêtre fille.
  • 🚀 Pousser : envoie la biblio complète (URL ou *).

④ Stockage

  • IndexedDB : fichiers (blobs) — quota réel affiché dans la barre « Stockage navigateur ».
  • localStorage : métadonnées uniquement — plafond navigateur ~5 Mo.
